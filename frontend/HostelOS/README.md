# HostelOS — Smart Hostel Management System

A full-featured, role-based hostel management web application built with HTML5, CSS3, and Vanilla JavaScript.

## How to Run

Simply open `index.html` in any modern web browser. No installation or server required.

## Features

### Student Portal
- Dashboard with room info, mess menu, notices & events
- My Room — details, inventory, roommate info
- Complaints — raise & track maintenance requests
- Fee Payment — view dues & payment history
- Mess Menu — weekly schedule + feedback
- Notice Board — live announcements
- Leave Request — apply & track outpass/leaves
- Visitor Registration

### Warden Panel
- Overview dashboard — occupancy, live activity feed
- Room Management — visual room grid
- Student Registry — searchable student list
- Complaint Manager — resolve complaints in real time
- Fee Tracker — collection status & reminders
- Leave Approvals — approve/reject with one click
- Notice Board — post & delete notices
- Staff & Maintenance — staff directory & task tracker
- Reports — analytics & attendance summary

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- Google Fonts: Syne + DM Sans
- No frameworks, no build tools, no dependencies
